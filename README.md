# Viagens com Alma

Cria uma app de viagens em português com Lovable Cloud para base de dados. Inclui: pesquisa de voos através de uma integração/API preparada para procurar preços e datas; área “Minhas Viagens” para criar e organizar viagens e voos; gestão de documentos associados a cada viagem (upload de PDFs, QR codes e registo de documentos recebidos por email, com interface preparada para isso). Faz uma interface moderna, clara e responsiva, com dashboard inicial e estados vazios úteis. Não uses dados reais de uma API sem configuração; cria fluxo e dados de demonstração para a pesquisa.

This project was built with [Lovable](https://lovable.dev).
